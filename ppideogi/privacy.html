1. 처리하는 정보와 목적

온라인 기능을 시작하면 무작위 친구 ID와 인증 토큰을 생성합니다. 서버에는 인증 토큰의 해시, 오리 이름, 골드, 보유 무기, 장착 무기, 점수, 친구 대전 기록, 동전 생성·수령 시간과 광고 보상 확인 기록을 저장합니다. 계정 인증, 게임 진행, 친구 대전, 보상 지급과 중복 지급 방지를 위한 정보입니다.

밥·물·생활 체력, 청소 상태, 소리 설정 및 계정 연결 정보는 기기에 저장합니다. 실명, 연락처 목록, 정확한 위치, 사진은 요청하지 않습니다. 기본 돌봄은 온라인 기능을 시작하지 않아도 이용할 수 있습니다. 서버는 연결·보안 처리를 위해 IP 주소를 일시적으로 처리합니다.

2. 친구와 공유

초대 링크에는 6자리 친구 ID만 포함됩니다. 인증 토큰은 포함되지 않습니다. 링크를 전달한 사람은 친구 ID를 볼 수 있고, 게임에서 오리 이름·무기·점수 등 대전에 필요한 정보를 확인할 수 있습니다. 공유 대상과 앱은 이용자가 직접 선택합니다.

3. 광고

광고가 활성화된 버전은 Google AdMob과 동의 관리 도구를 사용합니다. Google은 광고 제공·보안·성과 측정을 위해 IP 주소, 기기 및 광고 관련 식별자, 광고 상호작용, 진단 정보를 처리할 수 있습니다. IP 주소로 대략적인 위치가 추정될 수 있습니다. 앱은 개인 맞춤 광고를 요청하지 않으며 Apple의 추적 허용 팝업을 요청하지 않습니다. 설정의 ‘광고 개인정보 선택’에서 지원되는 동의 선택을 변경할 수 있습니다. 보상형 광고 시청은 선택 사항입니다.

보상형 광고의 완료 여부를 확인하기 위해 Google에 친구 ID와 일회성 보상 확인 값을 전달합니다. 서버는 Google의 서명을 검증한 완료 기록에 대해서만 골드를 지급합니다. Google 개인정보처리방침 · AdMob 개인정보 안내

4. 보관과 삭제

게임 진행에 필요한 온라인 기록은 계정을 유지하는 동안 보관합니다. 설정 → 계정 삭제를 선택하면 운영 서버의 계정·골드·무기·대전·동전·광고 보상 기록과 기기 진행을 삭제하고 인증 토큰을 무효화합니다. 다른 이용자의 계정은 유지됩니다. 삭제 후 온라인 기능을 직접 다시 시작하기 전까지 새 계정을 만들지 않습니다.

종료된 대전 기록은 7일, 광고 보상 확인 기록은 30일 후 정리합니다. 만료된 동전 기록은 만료 후 1일이 지나면 정리합니다. 정리 작업은 매시간 수행합니다. 복구용 일일 백업은 최대 7일 보관하며, 계정 삭제 시 운영 데이터와 보관 중인 백업에서 해당 이용자의 기록을 함께 제거합니다. 이전 시험 서버의 로컬 데이터 사본은 정식 서버 이전 검증 후 폐기했습니다. Google 등 외부 서비스가 처리한 정보의 보관 및 삭제에는 해당 서비스의 정책이 적용됩니다.

5. 권리와 문의

열람·정정·삭제 및 처리 관련 문의는 위 이메일로 접수할 수 있습니다. 계정 확인을 위해 친구 ID와 앱 내 확인을 요청할 수 있으나 비밀번호나 Apple 인증 코드를 요청하지 않습니다. 익명 계정이므로 앱 삭제나 기기 변경으로 연결 정보를 잃으면 계정 복구가 어려울 수 있습니다.

6. 외부 서비스와 변경

온라인 게임 서버는 Google Cloud의 대한민국 서울 리전에서 운영하며 게임 데이터와 복구용 백업을 저장합니다. Google AdMob 광고 및 GitHub Pages 지원 페이지는 각 제공자의 인프라에서 처리되며 국외 서버가 사용될 수 있습니다. Google Cloud 개인정보 안내를 확인할 수 있습니다.

지원 및 초대 페이지는 GitHub Pages에서 제공합니다. GitHub는 접속 보안과 서비스 제공을 위해 접속 정보를 처리할 수 있습니다. GitHub 개인정보처리방침을 확인할 수 있습니다. 처리 항목·목적·제공 서비스가 달라지면 이 페이지와 앱 내 안내를 갱신합니다.
